# Weather data

Source URL: https://cf-courses-data.s3.us.cloud-object-storage.appdomain.cloud/_0eYOqji3unP1tDNKWZMjg/weatherAUS-2.csv

SHA-256: `573fd715cd69fcacc4df32024d823b450ae3edaae7e8ff2eeb623adbed424014`

Source shape: 145,460 rows × 23 columns. The regional, labeled subset has 8,443 observations. The script verifies the whole downloaded file before filtering.

The source uses dates, station names, numeric observations, categorical wind directions, RainToday and RainTomorrow. Unknown targets are excluded; missing predictors are imputed within training. The raw CSV is ignored by git. Keep upstream attribution and consult source terms before redistributing it.
